## Rollback Examples

### Undo Last Commit (Keep Changes)

```bash
git reset --soft HEAD~1
```

### Undo Last Commit (Discard Changes)

```bash
git reset --hard HEAD~1
```

### View Specific Commit

```bash
git show abc1234
```

### Revert to Specific Page State

```bash
# Find commit for specific page
git log --grep="About SDIT" --oneline

# Checkout that version
git checkout abc1234 -- data/extracted/college_info/about.txt
```

## Branching Strategy (Optional)

For production use, consider:

```bash
# Create feature branch for new scraping run
git checkout -b scrape-2024-10-20

# Run pipeline
python -m src.main

# Review changes
git log --oneline

# Merge to main
git checkout main
git merge scrape-2024-10-20
```

## Commit Message Format

All automated commits follow this pattern:

**For Content Files:**

```
Added extracted text for '<Page Title>' (Category: <category_name>)
```

**For Metadata:**

```
Updated metadata: Added metadata for '<Page Title>'
```

**For Summary:**

```
Added pipeline execution summary
```

This structure enables:

- Easy searching: `git log --grep="Category: placements"`
- Rollback by page title
- Auditability of extraction progress
- Blame tracking per category
